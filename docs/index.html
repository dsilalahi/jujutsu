Fixed assumptions

  • 2,000 input tokens
  • 500 output tokens
  • 400 CU-seconds per request
  • 1 capacity unit = 86,400 CU-seconds per day

(2,000 × 100 + 500 × 400) / 1,000 = 400. That is Microsoft's published example. Cached input (10 CU-seconds per 1,000 tokens) is not applied. An F-SKU's daily budget is its CU count times 86,400.

Share of daily capacity

    This is the model-token cost only. Queries the agent runs against a warehouse, lakehouse, or semantic model consume more capacity. Copilot and Data Agent work is a background operation, smoothed over 24 hours, and it shares the SKU with reports, refreshes, and pipelines. 100% means the whole capacity is spoken for. Confirm rates on Copilot consumption and Data agent consumption before you size a purchase.
